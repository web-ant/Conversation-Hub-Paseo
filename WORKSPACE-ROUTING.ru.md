# Привязки каталогов рабочих пространств

В окне создания и редактирования папки находится список «Связанные каталоги
рабочих пространств». Добавьте полный путь к каждому проекту. Одна папка
может содержать несколько привязок, например каталоги `recmeet` и
`recmeet-openspec`.

Настройки плагина → «Распределение рабочих пространств по папкам»:

- включение автоматического распределения новых чатов;
- учёт вложенных каталогов;
- учёт git-worktree через каталог исходного репозитория;
- распределение подпроцессов, по умолчанию выключено.

Правила применяются на daemon при создании рабочего пространства и чата,
даже если боковая панель закрыта. Привязки действуют на собственном хосте
установки плагина. Сохранённые вкладки с собственными привязками получают
новый чат также в список участников вкладки.

Проверяются полные пути с границей каталога. `recmeet` не совпадает с
`recmeet-other`. Выбирается самый длинный совпадающий путь. При равнозначных
привязках разных папок чат остаётся без автоматического назначения. Ручное
размещение и явное исключение из папки имеют приоритет.

Добавление привязки не перемещает старые чаты. Отключение автоматизации и
удаление привязок также не меняет уже сохранённое размещение. Физические
каталоги, проекты и файлы не перемещаются.

Сохранение назначения использует штатный RPC настроек с проверкой ревизии:
при параллельном редактировании документ перечитывается. Чужие изменения
не заменяются старым снимком. Изменение списка чатов во время редактирования
названия папки не мешает сохранить её поля; параллельное изменение самих
полей папки требует повторной проверки.
